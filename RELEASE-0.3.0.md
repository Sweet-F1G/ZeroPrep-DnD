# Сказитель 0.3.0

Игра разговором и физическими кубиками остаётся основным сценарием.

- «Нулевая сессия · разговор» в боковой панели: пять вопросов, сохранение черновика, итог, исправления и фраза «подтверждаю договорённости». Начальную сцену затем запрашиваете голосом. При постоянном микрофоне текст отправляется сразу; в режиме по кнопке это зависит от настройки отправки.
- Персонажей пока называют отдельным ответом: «Лира и Бор». Следующий ответ — предыстории и при необходимости «Лира, HP 17, КД 14; Бор, HP 25, КД 16». Бонусы остаются нулевыми до заполнения листов. Мастер предупреждает об этом; полноценное создание класса/уровня ещё впереди.
- В прямом голосовом режиме обычный ожидаемый бросок: «на кубике четырнадцать». Бонус прибавляет приложение. При ошибке есть отмена хода.
- Для одного ожидаемого изменения HP: «подтверждаю изменения» или «отклоняю изменения». При нескольких предложениях используйте карточки — массового неподтверждённого списания нет.
- Бесплатный резерв ведущего: OpenRouter, закреплённая Gemma 4 31B `:free`. Включите в «Модели и голос» и добавьте отдельный ключ OpenRouter в список совместимого API. Ключи Groq сохраняются отдельно. Резерв работает для ведущего и сводок; STT не заменяет.
- Точный использованный провайдер/модель видны в расходе токенов. При ответе резерва на столе появляется пометка. Каталог и потолок цены запрещают платное переключение.

Обновлено рабочее приложение. Установщик 0.3.0 не выпущен: сборка остановлена по просьбе пользователя. Новые установщики собираются только по отдельному запросу. Последний завершённый установщик — 0.2.3. Для облачного резерва нужен собственный OpenRouter-ключ; вставляйте его только в приложении.

Полный автоматический бой, все навыки/сейвы/ресурсы, инвентарь, факты-обещания и генерация картинок остаются в дорожной карте. Существующая игра и ключи при обновлении не перезаписываются.

Проверка выпуска: 39 автоматических тестов прошли; запуск упакованного приложения на чистом профиле и нулевая сессия проверены отдельно. Реальный ответ OpenRouter не проверен без отдельного ключа.
