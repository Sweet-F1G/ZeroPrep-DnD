## Честное позиционирование

Идея AI-мастера, инвентаря и постоянной памяти уже существует в других проектах. Возможная специализация Сказителя: простой установщик, русский голос, физические кубики, минимальные расходы и работа группы за одним столом. Это целевое направление, а не доказанная уникальность.

Перед написанием большого боевого ядра сравнить Open Dungeon Master с нашим приложением на одном небольшом сценарии и доступном бесплатном backend. Проверить: удобство установки на Mac 8 ГБ, русский голос, передача физических бросков, применение HP/ресурсов, постоянство NPC/обещаний, расход запросов и исправление ошибки. Ничего не мигрировать и не вводить реальные ключи автоматически.

Если подходящий компонент/архитектура экономит разработку, рассмотреть адаптацию после проверки лицензии. Полный переход на другой проект — отдельное решение пользователя после конкретного сравнения, с резервной копией сохранений.

## Каталог бесплатных API

[awesome-free-llm-apis](https://github.com/mnfst/awesome-free-llm-apis) — полезный перечень кандидатов, не гарантия вечной бесплатности и не самостоятельный API. Перед использованием сверять официальный тариф, модель, реальные ограничения, обработку данных, JSON и качество русского на тестовых игровых сценах.

Начать с бесплатного Groq и имеющихся резервов; затем изучить два независимых резервных подключения: OpenRouter с явно выбранной бесплатной моделью и доступные starter-модели Ollama Cloud Free. По текущему официальному тарифу Ollama Free даёт стартовые usage-кредиты и ограниченный набор моделей; не считать весь облачный каталог постоянно бесплатным. Количество ключей не равно количеству независимых квот. Ключи Groq одной организации расходуют общую квоту. С версии 0.3.0 добавлен отдельный бесплатный резерв OpenRouter → Gemma 4 31B для текстового ведущего и сводок, после отказа Groq. Распознавание не переключается на этот текстовый резерв.

Не вводить случайный роутер, меняющий модель каждый ход. Профили/порядок переключения должны быть видны пользователю, бесплатно/платно задаётся явно. Для изображений принят исключительно бесплатный режим без платного fallback.

Источники: [Groq](https://console.groq.com/docs/rate-limits), [OpenRouter](https://openrouter.ai/docs/api_reference/limits), [Ollama pricing](https://ollama.com/pricing), [Ollama cloud](https://docs.ollama.com/cloud), [AI Horde](https://aihorde.net/).

## Что берём из Open Dungeon Master для игры за одним столом

Сравнение по README и `docs/engines.md`, `docs/rules-coverage.md` ветки main, прочитанным 18.10.2026; не результат прохождения кампании в ODM. В README рекомендуется установка stable; main может содержать более новые возможности. Прямого переноса исходников нет.

| Основа ODM по документации | Сказитель сейчас | Решение |
| --- | --- | --- |
| Модель заявляет намерение, сервер проверяет изменения | Проверенный обычный d20 и явное подтверждение HP, атомарное сохранение хода и отмена | Сохранить эту границу; повествование не является доказательством потери ресурсов |
| Физические кубики и запросы бросков | Физический d20; в 0.3.0 результат можно сообщить голосом | Сначала вопрос/ставки → реальный бросок → одно число → вычисленный итог → рассказ |
| Полноценные листы, спасброски, слоты и отдых | Частичный список навыков, HP и КД; ресурсов/сейвов пока нет | Следующий обязательный этап: все навыки и сейвы, заряды, состояния, отдых; голосовые заявки вместо панели обязательных карточек |
| Атаки и боевые реакции вычисляет сервер | Автобоя нет; есть паузы и ручное подтверждение предложенного HP | Не включать автоматический урон до проверки попадания, защит, реакции, сопротивлений и временных HP |
| Журнал, сводки, память глав и поиск | Полный журнал, сводка, отдельный подтверждённый договор кампании | Далее отдельные факты/NPC/обещания с источником и состоянием; извлечение после сцены, а не несколько моделей каждый ход |
| Подготовка мира, героев и завязки | Нулевая сессия 0.3.0: фиксированные вопросы и исправляемый итог | Позднее свободный диалог и полноценные листы; сейчас не выдавать временные характеристики за корректный D&D-билд |
| Карточки действий, карты и многопользовательский веб-стол | Один общий компьютер и голос | Не повторять весь интерфейс: ролевые решения произносятся; экран — справка, лист и возможность исправления |

Приоритет после 0.3.0: листы/спасброски/ресурсы и факты-память → личный и общий инвентарь → проверяемый бой. Генерация изображений — необязательная бесплатная атмосферная функция, не условие продолжения игры.

## Выбранный бесплатный резерв

`google/gemma-4-31b-it:free` через OpenRouter: по актуальному каталогу нулевые цены, контекст 262144, `response_format` для JSON. Выбор основан на доступности, многоязычности и соответствии протоколу приложения; качество длинной русской кампании ещё не проверялось на реальном резервном ключе пользователя. Модель закреплена: случайный роутер не выбирает новый стиль рассказчика каждый ход.

Настройки: основной совместимый API — Groq, затем «Если ведущий Groq недоступен» → OpenRouter, в списке «Совместимый API» добавить отдельный OpenRouter-ключ. Ключ Groq туда переносить не нужно. Сохранённые старые ключи автоматически переводятся в собственный список Groq перед включением внешнего резерва. Ключи остаются в Keychain и не входят в экспорт кампании/установщик.

Проверка резервирования выполнена на имитации 429/400, охлаждения ключей и изменения цены каталога; реальный облачный ответ Gemma в этой поставке не проверен. Бесплатные лимиты и политика доступа могут меняться: [модель](https://openrouter.ai/google/gemma-4-31b-it:free), [лимиты](https://openrouter.ai/docs/api_reference/limits), [ограничение цены](https://openrouter.ai/docs/guides/routing/provider-selection).
