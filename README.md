# Сказитель · демо 0.2.1

Отдельное приложение для macOS на Apple Silicon. На этом компьютере также установлена локальная озвучка Silero. Откройте `Skazitel.app` двойным щелчком. На текущем компьютере также создан ярлык «Сказитель» на рабочем столе; он открывает это же приложение. Встроенная иконка — изумрудный d20 с золотыми гранями. Не перемещайте отдельно папки Saves и LocalVoice: они используются рядом с приложением. Node.js включён в приложение; npm, Python и установка пакетов для запуска не нужны. Windows-сборки пока нет.

## Быстрый тест без ключа

1. Нажмите «Импортировать Теона и Альвари» или создайте свою кампанию и героев.
2. Нажмите «Опиши, где мы находимся».
3. Отправьте действие: «Осматриваю следы».
4. Бросьте настоящий d20. Внесите число на грани, без бонусов, и подтвердите.
5. Программа добавит бонус персонажа, сравнит итог со сложностью и запишет событие. Проверьте «Отменить ход», экспорт и повторное открытие.

Учебный режим использует небольшую заготовленную сцену. Он проверяет интерфейс и расчёты; свободного ИИ в нём нет. Системный голос можно включить без ключа. Распознавание микрофона требует ключа Groq, OpenAI или Gemini даже в учебном режиме.

## Свободная игра с ИИ

Откройте «Модели и голос» внизу слева. Параметры неиспользуемых моделей скрываются; списки ключей отмечены «Используется сейчас» или «Сейчас не используется». Для Groq ведущий и распознавание используют общий список ключей. Выберите модель ведущего:

- **OpenAI:** ключ OpenAI и ID модели с Chat Completions и JSON-ответами. В форме стоит стартовый пример; доступность зависит от вашего аккаунта.
- **Gemini:** ключ Google AI Studio и ID модели с `generateContent` и JSON-выводом.
- **Совместимый API:** Base URL, модель и при необходимости ключ. Например, OpenRouter или локальный сервер с `/chat/completions`. Поддержка формата `response_format: {type: "json_object"}` обязательна.

Распознавание речи настраивается независимо: Groq Whisper, OpenAI Transcriptions или понимание аудио Gemini. Для Groq выберите `whisper-large-v3-turbo`. Ключи Groq задаются в отдельном списке «Groq»; прежний ключ совместимого API автоматически используется как основной, пока не сохранён отдельный список Groq. Ключ другого провайдера в Groq не пересылается. Озвучивание: локальный Silero, системный голос macOS, OpenAI TTS либо выключено. Silero работает без API-ключа: выберите «Silero · локально, без API», голос и нажмите «Послушать выбранный голос». Полностью локальным является только озвучивание — ведущий и распознавание речи настраиваются отдельно. Для полностью голосового теста с одним облачным ключом удобно использовать OpenAI для распознавания, ведущего и TTS; для Gemini можно использовать его распознавание и ведущего вместе с системным голосом.

Выберите героя. Пробел — основная клавиша push-to-talk: удерживайте его вне поля ввода. В текстовом поле пробел печатает текст; кнопка «К голосу» возвращает фокус на микрофон. Также можно удерживать кнопку микрофона: произнесите имя и действие, затем отпустите. Разрешите доступ к микрофону по запросу macOS. По умолчанию проверьте расшифровку и нажмите отправку. Если включено «Сразу отправить реплику мастеру», этот шаг выполняется автоматически. Запись ограничена одной минутой, дорожка микрофона закрывается после отпускания кнопки. Если окно потеряло фокус или кнопка отпущена до завершения запроса разрешения, начните запись ещё раз.

Когда мастер ожидает бросок, можно удержать микрофон и сказать «Теон, на кубике четырнадцать». Программа предложит число, если распознано ровно одно значение от 1 до 20. Проверьте его и подтвердите кнопкой. Бонусы произносить не нужно. Непонятную расшифровку можно заменить ручным вводом.

Кнопка «Перебить мастера» и короткий пробел вне текстовых полей прерывают озвучивание. Esc приложением больше не перехватывается. Это не откат состоявшегося хода: для него есть «Отменить ход».

## Что уже работает

- Несколько независимых кампаний; новая кампания с произвольным миром, героями и заметками.
- Импорт вашей игры с исходным Markdown, без продолжения сюжета за игроков.
- Выбор героя, редактирование HP, КД, характеристик и полных бонусов навыков.
- Голос по кнопке с проверкой расшифровки, текстовый ввод и озвучивание ответа.
- Обычные проверки d20: бросок задаёт игрок; итог и успех вычисляет программа.
- Изменение HP от модели применяется только после подтверждения игроком.
- Локальный журнал, автоматическое сохранение, JSON-экспорт и импорт.
- Отмена последних 20 действий; неуспешный запрос API не расходует бросок и не меняет кампанию.

## Границы этой версии

Это прототип ведущего, а не полный движок правил D&D. Преимущество/помеха, боевые атаки, критические попадания, урон кубиками, инициатива, заклинания, ячейки и авторские ресурсы пока не автоматизированы. Их можно обсуждать и фиксировать в журнале, но программа их не валидирует. Обычная проверка d20 сравнивается с Сл; натуральные 1 и 20 не переопределяют итог.

HP и результаты поддержанных проверок контролирует код. Повествование остаётся ответом модели и может ошибаться: сверяйте спорные описания с журналом. Импортируются только сведения из предоставленного файла; отдельного скрытого архива предыдущей переписки у приложения нет. КД Альвари 12 — временная настройка по варианту со щитом из документа, её можно изменить на 10 в редакторе листа.

Долгая память пока реализована передачей материалов и журнала целиком. Есть явный предел контекста 180 000 символов; автоматического суммирования и поиска по памяти нет. Длинные кампании увеличивают расходы. Если достигнут предел, приложение остановит запрос вместо скрытого удаления начала истории.

Для Silero держите папку `LocalVoice` рядом с `Skazitel.app`. Здесь находятся русская модель v5.6 и отдельное Python-окружение с PyTorch. Модель загружается один раз при первом озвучивании и остаётся в памяти; при закрытии приложения процесс модели завершается. По умолчанию выбран мужской голос «Евгений». Также доступны «Айдар», «Ксения» в двух вариантах и «Байя». Числа, d20 и базовые обозначения характеристик преобразуются в произносимый текст. Модель работает на CPU, без сетевых соединений. Для новой установки есть `Setup-local-voice.command`; окружение текущей машины не является переносимым. Исходная модель Silero распространяется по лицензии из `LocalVoice/Silero-LICENSE.txt`.

В этой версии голос работает цепочкой «распознавание → текстовая модель → озвучивание», с задержкой между этапами. Нативные OpenAI Realtime, Gemini Live, Grok Voice и другие непрерывные голосовые сессии ещё не реализованы.

## Данные и ключи

Сохранения и несекретные настройки находятся в `Saves` рядом с приложением. Не перемещайте приложение без этой папки, если хотите сохранить доступ к локальным кампаниям. Для переноса используйте JSON-экспорт. В macOS-приложении ключи сохраняются в защищённой Связке ключей и восстанавливаются после закрытия. В настройках видна отметка «ключ подключён»; само значение в интерфейс не возвращается. Пустое поле при сохранении ничего не удаляет, новый ключ заменяет прежний. Удаление всех ключей выполняется отдельной кнопкой с повторным подтверждением. При запуске только Node-сервера через браузер ключи остаются в памяти до закрытия сервера. Ключи не записываются в Saves и не попадают в экспорт или архив сборки.

При отправке игрового действия выбранный провайдер модели получает материалы кампании, листы персонажей и журнал, включая импортированный файл. Провайдер распознавания получает запись после отпускания кнопки. OpenAI TTS получает текст ответа при включённой облачной озвучке; системный голос использует macOS. Записи микрофона на диск приложением не сохраняются. Отправка и озвучивание через облако оплачиваются по тарифам ваших аккаунтов.

Локальный сервер слушает только 127.0.0.1 на случайном порту, проверяет Origin, Host и токен сессии. При закрытии приложения сервер завершается. Это локальный прототип для одного пользователя, без удалённого доступа и многопользовательской авторизации.

## Проверка и исходники

Проверено: сборка macOS, локальный запуск, импорт исходной кампании, прохождение учебной проверки через интерфейс, отсутствие ошибок в консоли, экспорт/импорт и сохранения после перезапуска. Автотесты проверяют расчёты, недопустимые броски, подтверждение HP, откат, блокировку обхода ожидаемого броска, атомарность при ошибке модели, сохранение и исключение ключей из файлов. Совместимый API проверен локальной mock-моделью. Groq STT проверен подставными ответами: адрес, передача WAV, язык ru, подсказка имён, выбор модели и изоляция ключей разных провайдеров. Реальную запись микрофона через Groq нужно проверить с вашим ключом.

Локальная озвучка Silero дополнительно проверена реальной генерацией WAV, двумя голосами, очередью запросов и HTTP-маршрутом приложения. Реальные облачные запросы и сквозной разговор через микрофон не проверены: API-ключи не предоставлялись. Для первого такого теста внесите свой ключ в интерфейсе. Не отправляйте ключ в чат.

Исходники находятся в `src`. Автотесты: `cd src && npm test`. Сборка: `src/build-mac.sh` (нужны Swift CLI и Node.js; `SKAZITEL_NODE` позволяет указать автономную сборку Node.js). Для разработки сервер запускается командой `node server.mjs` из `src`. Альтернатива оболочке — `Start-browser.command`, затем локальный адрес из терминала в Chrome. Закрытие окна терминала останавливает этот сервер.

Хранение ключей проверено тестовым значением в настоящей Связке ключей macOS: повторное открытие настроек, сохранение пустого поля, полный перезапуск и явное удаление с подтверждением. Тестовое значение после проверки удалено.

## Панель героев и реакции

Журнал прокручивается отдельно от правой панели героев: HP не уезжают вместе с историей. Для небольшой высоты окна карточки становятся компактнее; правую панель можно прокручивать независимо.

«Перебить мастера» или короткий пробел останавливает озвучивание и даёт ввести вмешательство. Удержание пробела также останавливает голос перед записью. Уже подтверждённый ход можно отменить отдельной кнопкой «Отменить ход».

Перед угрозой, в которую ещё можно вмешаться, модель должна вернуть reaction_request: prompt, stakes и timeoutSeconds. Приложение показывает отдельную карточку и ограничивает длительность диапазоном 3–30 секунд. Модель выбирает время по срочности: 3–6 секунд для внезапной боевой реакции, 7–15 для развивающейся опасности, 16–30 для обсуждения или переговоров. Отсчёт начинается после окончания озвучки; ввод текста, запись голоса, кнопка вмешательства или потеря фокуса ставят его на паузу. Если время истекло без начала ответа, приложение отправляет мастеру отказ от вмешательства. Физический бросок всё равно подтверждается отдельно. После перезапуска приложения активная реакция восстанавливается на паузе.

Модель отвечает за распознавание подходящих ситуаций; движок проверяет формат паузы и запрещает совмещать её с готовым броском или предложенным уроном. Для проверки без ключа в учебном режиме отправьте «гипноз».

Список возможных будущих доработок: [ROADMAP.md](ROADMAP.md).

## Новые режимы микрофона, память и расход

Внизу игрового стола переключайте «По кнопке / пробелу» и «Постоянное прослушивание». В постоянном режиме дополнительно нажмите «Включить микрофон». Он работает, пока приложение активно; смена кампании, настройки и потеря фокуса останавливают захват. Индикатор показывает состояние микрофона. Локальный детектор выделяет активные участки и заканчивает реплику после примерно 0,75 с тишины; непрерывные реплики ограничены 30 секундами. В облако уходит только завершённая реплика, без хранения записей на диске. Очередь ограничена тремя репликами; переполнение выключает микрофон. Перед отправкой действия по голосу требуется однозначное имя героя в начале реплики; иначе текст остаётся для ручной проверки. Физический бросок всегда подтверждается отдельно. В настройках можно выбрать перебивку от любой речи или от распознанного обращения «мастер» / «сказитель» (второй вариант реагирует после распознавания).

Короткий пробел прерывает рассказ без записи и без ошибки о слишком короткой записи. В режиме по кнопке удержание дольше 240 мс включает запись, отпускание её завершает. В постоянном режиме пробел прерывает мастера, а голос слушает уже включённый микрофон. В текстовых полях пробел вводит текст; для возврата к голосовым клавишам есть кнопка «К голосу».

Озвученный ответ фиксируется по частям: завершённые фразы остаются в журнале, текущая и будущие части при перебивке отбрасываются. Запрошенные проверки, реакции и изменения HP из ответа доступны только после полного озвучивания. Токены за уже сгенерированный ответ при перебивке не возвращаются. Непроизнесённая часть не передаётся модели как состоявшееся событие.

«Память» позволяет создать или исправить сводку старых событий. Последние 12 записей остаются подробными. Автосводка включена по умолчанию и создаётся при росте несжатой истории примерно до 14 тысяч символов; её запрос учитывается в статистике. Полный журнал не удаляется. Сводка не сокращает исходные материалы кампании и не заменяет точные HP, броски, ожидаемые действия и предложения изменений. При импорте сводка создаётся заново; при отмене/изменении покрытой истории проверяется её актуальность.

«Расход токенов» показывает фактический usage, кеш, рассуждения, запросы без usage и снимок заголовков лимитов. Данные записываются отдельно в Saves/usage.json (до 10 тысяч последних запросов), исключаются из экспорта кампаний и архива сборки; ключи и содержимое запросов туда не записываются. Сессия — текущий запуск сервера, сутки указаны по UTC. Отсутствующие значения обозначаются «—». Кеш и рассуждения показаны как части общего расхода и повторно не прибавляются. Локальная озвучка Silero не создаёт расходов API.

Проверка голоса в постоянном режиме на реальном игровом столе ещё нужна: используется простой локальный детектор аудиоактивности и эхоподавление браузера. Наушники облегчают подавление собственного голоса мастера; шум и одновременная речь могут вызывать ложные срабатывания.

Доступ к Связке ключей выполняется отдельным подписанным компонентом KeyStore.app внутри приложения. Сборщик сохраняет его без изменений при обновлении интерфейса. Компонент не содержит самих ключей; они остаются в системной Связке ключей.

Для v0.2 прошли 26 автоматических проверок, включая статистику и её восстановление, сводку, фиксацию озвученных частей, локальный детектор и закрытие микрофона при смене режима во время запроса разрешения. Перебивка пробелом проверена через интерфейс с настоящей озвучкой Silero. Сквозной постоянный разговор с несколькими живыми игроками ещё не проверен.

## Основной ключ и резервы · 0.2.1

В «Модели и голос» откройте список нужного сервиса: Groq, OpenAI, Gemini или совместимый API. Первая строка — основной ключ, остальные — резервы по порядку. Кнопка «＋ Добавить ключ» добавляет строку; стрелки меняют приоритет, «Удалить» убирает строку. Можно сохранить 10 ключей одного типа (до 100 строк на сервис в пределах общего объёма Связки ключей). Изменения применяются кнопкой «Сохранить настройки». После сохранения у каждой строки появляется подтверждение; значения скрыты, пустые поля не стирают существующие ключи. Все ключи и порядок восстанавливаются после перезапуска macOS-приложения. В браузерном запуске без помощника Keychain ключи доступны только до закрытия сервера — это явно указано в настройках.

При HTTP 401, 402, 403, 408, 429, ошибках сервера 5xx или сети пробуется следующий доступный ключ. Учитывается Retry-After, отклонённые ключи временно пропускаются. После паузы снова пробуется основной. Лимиты ведущего и распознавания отслеживаются отдельно. Некорректный запрос (например, HTTP 400) или некорректный JSON ответа не запускают перебор ключей. Временные статусы попыток действуют до перезапуска, сами ключи сохраняются постоянно. В настройках показаны последний результат и время паузы. Запросы и расход всех попыток учитываются статистикой; остаток лимита относится к ключу последнего ответа, не к сумме резервов.

Проверено на тестовых ключах: сохранение десяти ключей и порядка через перезапуск, пустые поля, перестановка и удаление, переход 401 → 429 → успех с единственным ходом в журнале, скрытие секретов в API и экспорте. Новые реальные резервные ключи нужно ввести самостоятельно в приложении.

## Единый установщик macOS · 0.2.2

Готовый пакет находится в `../Installers/Skazitel-0.2.2-macOS-AppleSilicon.pkg`. Он включает Silero, переносимый Python и библиотеки. Нужны Apple Silicon и macOS 14+. В распространяемую сборку не копируются Saves, встроенные частные сценарии, примеры, ключи или прежняя вложенная копия приложения.

Сборка: `python3 src/build-installer.py`. Можно указать SKAZITEL_PYTHON (корень standalone Python 3.12), SKAZITEL_NODE, SKAZITEL_VOICE_SOURCE и SKAZITEL_BUILD_CACHE. Лицензия Node хранится в src/assets/Node-LICENSE.txt. Установленная сборка использует Application Support/Skazitel/Saves, переносная версия продолжает использовать Saves рядом с приложением.

## Живой разговор · 0.2.3

Выберите «Постоянное прослушивание» и нажмите крупную кнопку «🎙 Включить микрофон» в блоке «Живой разговор с мастером». При включении кнопка меняется на «■ Выключить микрофон» и показывает активное состояние. После распознавания реплика сразу отправляется мастеру; настройка «Показать текст для проверки» относится только к режиму по кнопке. Названный в начале реплики герой определяется автоматически; без имени используется герой, выбранный в момент записи. Текстовый черновик при голосовой отправке сохраняется.

Результаты бросков, изменения HP и неоднозначный выбор героя требуют явного действия. Потеря фокуса, смена кампании или открытие настроек выключают постоянный микрофон, как и прежде. Это последовательное распознавание и генерация ответа: остаётся задержка определения паузы и ответа API. Проверено на тестовом распознавателе без использования реальных API-ключей.

Обновлённый установщик: ../Installers/Skazitel-0.2.3-macOS-AppleSilicon.pkg. Silero включён; личные кампании и ключи не включены.
