# Сказитель 0.4.0

Рабочее приложение обновлено. Новый установщик не создавался; последняя готовая установочная версия остаётся 0.2.3. Все последующие установщики — только по отдельной просьбе.

## Что попробовать

- «Новая игра»: выбрать 2014 или 2024, пройти нулевую сессию разговором. Существующие партии сохраняют прежние договорённости.
- «Лист» рядом с героем: все навыки и сейвы, ручной/расчётный режим, HP/КД, способности/ячейки и правила восстановления. Лист старого героя помечен как требующий сверки. Класс сам по себе пока не создаёт корректный полный набор способностей.
- Физическое преимущество: «на кубиках двенадцать и восемь». Приложение выбирает нужный результат. Отдельный спасбросок использует saves, а не бонус проверки характеристики.
- «Запиши обещание вернуть кольцо до заката» или «Запомни: ключ хранится у мельника». Запись сохраняется отдельно от сводки. «Кампания → Факты и обещания» показывает её источник и статус.
- «Кампания → Вещи и казна»: общий/личный инвентарь, передача, расход и монеты. Использование зелья пока само по себе не рассчитывает лечение. Предложения модели применяются только после подтверждения: «подтверждаю действие», при нескольких — «подтверждаю действие 2».
- HP можно подтвердить по имени: «Лира, подтверждаю изменения». Несколько изменений одного героя остаются отдельными карточками.
- «Кампания → Иллюстрации»: бесплатная очередь AI Horde. Анонимные описание и результат публичны, что явно указано до отправки. Материалы/тайны партии автоматически не передаются. Есть ожидание, проверка готовности, кеш и локальная галерея. Реальная очередь не испытывалась: проверены протокол и ошибки на тестовом API.
- «Кампания → Поиск по хронике»: поиск в полном архиве. В основном разговоре показывается только недавняя часть.

## Сохранения и память

Основная база — `Saves/campaigns.sqlite`, совместимая копия — `Saves/campaigns.json`. До миграции исходный JSON сохраняется в `Saves/Backups`. API-ключи остаются в Keychain, в базе партии их нет. Две текущие пользовательские партии предварительно проверены на отдельной локальной копии: ID, HP, КД, старые бонусы, полная хроника и канон сохранены; исходный файл во время испытания не менялся.

Активные обязательства передаются каждый ход. Для больших материалов и инвентаря передаются релевантные выдержки/элементы; оригиналы доступны через поиск. Снижение размера запроса не доказывает отсутствие ошибок на любой долгой кампании. Реальные токены и используемая модель видны в расходе.

Промпт — `src/prompts.mjs`: core, dice, tempo, state, protocol, edition. Предпочтения стиля и строгости остаются в договоре кампании.

## Что ещё не готово

Полный боевой движок, автоурон после реакций/защит, полная автоматизация состояний и концентрации, классы/заклинания/повышение уровней, полноценная торговля/attunement, свободный ИИ-конструктор нулевой сессии, импорт изображений вместе с JSON и Windows-поставка. Это остаётся в ROADMAP.md. Вся дорожная карта этим выпуском не закрыта.

Проверка выпуска: 53 автоматических теста прошли, отдельно проверены перенос копий двух пользовательских партий и запуск упакованного приложения на чистом профиле. Тесты облачного протокола используют имитацию API, не реальные пользовательские ключи.

## Уточнение интерфейса 18 октября

Личный инвентарь открывается с карточки героя; общие вещи и казна — над героями. Кнопка постоянного микрофона перенесена рядом с «Озвучивать», большой баннер убран. Нажатие на портрет/«＋ портрет» открывает бесплатную генерацию с выбранным героем. Мастер может редко предложить иллюстрацию сцены/босса: карточка появляется после завершения реплики и открывает редактируемое описание, отправка — только с отдельным согласием. Непрослушанное предложение при перебивании не сохраняется. Проверки: 55 тестов, включая два новых теста предложений; личный инвентарь, портрет и описание сцены проверены в интерфейсе на тестовой партии.
